¿Qué es un IBAN?

IBAN significa International Bank Account Number (Número de Cuenta Bancaria Internacional). Es una forma estandarizada de identificar cuentas bancarias a través de fronteras, usada en más de 95 países. Un IBAN contiene un código de país de dos letras, dos dígitos de control y una Basic Bank Account Number (BBAN) con el código bancario nacional, sucursal y número de cuenta.

El sistema IBAN fue desarrollado por el European Committee for Banking Standards (ECBS) y adoptado como ISO 13616. Hoy, todas las transferencias SEPA (Single Euro Payments Area) requieren IBAN, siendo esencial para la banca internacional en Europa y más allá.

Preguntas frecuentes

¿Son IBAN reales?

No. Los IBAN generados aquí son matemáticamente válidos (pasan la verificación MOD-97) pero usan códigos bancarios y números de cuenta aleatorios. Son solo para fines de prueba — no los uses para transferencias reales.

¿Cómo funciona el dígito de control del IBAN?

El IBAN usa el algoritmo MOD-97 (ISO 7064). Las letras del código de país se convierten a números (A=10, B=11, ..., Z=35), la cadena se reordena y el resultado debe ser igual a 1 módulo 97. Esto detecta el 99,94% de los errores de escritura.Aprende más →

¿Mis datos están seguros?
