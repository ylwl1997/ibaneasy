什么是 IBAN？

IBAN 代表国际银行账号。它是一种跨国境识别银行账户的标准化方式，在全球 95+ 个国家使用。IBAN 包含两位字母国家代码、两位校验位，以及包含国内银行代码、分行代码和账号的基本银行账号（BBAN）。

IBAN 系统由欧洲银行标准委员会（ECBS）开发，后被采纳为 ISO 13616 标准。如今，所有 SEPA（单一欧元支付区）转账都需要 IBAN，使其成为欧洲及全球国际银行业务的必需品。

常见问题

这些 IBAN 是真实的吗？

不是。这里生成的 IBAN 数学上有效（通过 MOD-97 校验位验证），但使用随机生成的银行代码和账号。它们仅供测试用途 — 请勿用于实际的银行转账。

IBAN 校验位如何工作？

IBAN 使用 MOD-97 算法（ISO 7064）。将国家代码字母转换为数字（A=10，B=11，...，Z=35），重新排列字符串，结果必须等于 1 对 97 取模。这能捕捉 99.94% 的输入错误。了解更多 →
